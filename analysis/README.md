## 虚构论文设定

虚构研究讨论一个使用 Cryo-X 工质的两级 Venturi 阀，研究问题是：低温热状态、阀开度和分级压降如何共同影响空化波动。

设定的范围为：

| 项目 | 虚构条件 |
|---|---|
| 几何 | 两级 Venturi 阀，喉部 6 mm |
| 工质 | Cryo-X 虚构低温工质 |
| 温度 | 72–86 K |
| 入口压力 | 0.4–0.8 MPa |
| 质量流量 | 0.12–0.22 kg/s |
| 诊断 | 50 kfps 高速图像、100 kHz 动态压力、壁面温度 |

## Flash 模式展示

Flash 报告快速回答：

1. 作者做了什么；
2. 研究漏洞在哪里；
3. 工质、工况、几何和边界条件限制是什么；
4. 核心概念是否真正量化；
5. 下一步是否值得 Deep 精读。

![虚构阀开度比较](images/opening_comparison.png)

虚构结果设定为 70% 开度的峰值汽相代理指标最高，但报告同时指出：没有材料侵蚀试验时，不能把代理指标下降直接解释为“侵蚀风险下降”。

## Deep 模式展示

Deep 报告按三层组织：

- Layer 1：研究问题、假设、对象、方法和证据链；
- Layer 2：分区指标、图表、实验控制、模型和验证层级；
- Layer 3：漏洞、场景边界、量化成熟度和 P0/P1/P2 迁移计划。

## 这个示例体现的表格规则

- 表头横向和纵向居中；
- 最左侧分类列的短标签居中；
- 状态、优先级、数值和短标题居中；
- 长证据、解释、限制和建议左对齐；
- 所有单元格默认纵向居中，并有统一内边距；
- 表格使用轻边框、交替行色和有意设置的列宽。

## 适用提醒

虚构数据只能用于演示阅读流程、批判框架和排版，不能替代真实论文阅读。实际使用时，Paperzh Reading Skill 会优先依据用户提供的 PDF，并区分“论文明确”“直接观察”“合理推断”和“无法确定”。
