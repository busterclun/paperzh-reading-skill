# Paperzh Reading Skill

Codex skill for evidence-based research-paper reading and comparison.

## Modes

- **Flash** — batch-friendly rapid reading, one-minute paper cards, horizontal comparison, explicit vulnerabilities, scenario boundaries, and concept-quantification checks.
- **Deep** — three-layer close reading covering research logic, methods, figures, tables, formulas, evidence chains, critical appraisal, and prioritized research transfer.

Both modes deliver editable Chinese `.docx` reports with:

- Chinese headings in SimHei;
- Chinese body text in SimSun;
- English text and numbers in Times New Roman;
- simple, readable styles and evidence locations.

The skill folder name and YAML `name` are `paperzh-reading`; the user-facing display name is `Paperzh Reading Skill`.

See [SKILL.md](SKILL.md) for the complete workflow and [references](references/) for mode-specific schemas and DOCX checks.
