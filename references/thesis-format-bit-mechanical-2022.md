# 毕业设计/论文 Word 交付格式

## 适用范围

本文件把用户提供的《机械与车辆学院本科生毕业设计（论文）书写规范及电子资料存档要求（2022年6月）》整理为可执行的 DOCX 交付配置。它是 `paperzh-reading` 的学校格式覆盖层：当用户要求毕业设计/论文格式，或明确要求按该附件排版时，优先使用本文件。

如果用户提供了更新版校级、学院级模板，更新版模板优先；不要把不同学校的页边距、编号、字体规则混在同一份文档中。

## 页面与页眉页脚

| 项目 | 要求 |
|---|---|
| 纸张 | A4，纵向 |
| 页边距 | 上 3.5 cm；下 2.6 cm；左 3.0 cm；右 2.6 cm |
| 页眉 | 距顶 2.4 cm |
| 页脚 | 距底 2.0 cm |
| 装订线 | 0 cm |
| 页眉内容 | `北京理工大学本科生毕业设计（论文）` |
| 页眉字体 | 宋体，四号（14 pt），居中，字间距加宽 0.5 pt |
| 页脚内容 | 页码 |
| 页脚字体 | 宋体，五号（10.5 pt），居中 |

实现时将页眉/页脚距离和正文页边距分别写入 DOCX section properties；不要只用空格模拟页眉位置。页码应使用真正的 PAGE 字段，以便分页后自动更新。

## 字体、标题与段落

| 对象 | 字体与字号 | 对齐 | 段前/段后 | 行距 |
|---|---|---|---|---|
| 一级/章标题，例如 `第1章` | 黑体，三号（16 pt），加粗 | 正文中居中 | 段前 0.5 行；段后 1 行 | 1.5 倍 |
| 二级标题，例如 `1.1` | 黑体，四号（14 pt），加粗 | 左对齐 | 段前 0.5 行；段后 0 行 | 1.5 倍 |
| 三级标题，例如 `1.1.1` | 黑体，小四（12 pt），加粗 | 左对齐 | 段前 0.5 行；段后 0 行 | 1.5 倍 |
| 正文 | 宋体，小四（12 pt） | 按内容需要，通常两端对齐 | 段前 0 行；段后 0 行 | 固定值 22 pt |
| 英文、拉丁字母、数字 | Times New Roman | 随所在段落 | 随所在样式 | 随所在样式 |

标题和正文中的混排字符应在 run/style 层面同时指定 East Asia 字体和 ASCII 字体：中文标题/正文分别使用黑体/宋体，英文及数字使用 Times New Roman。不能只设置一个全局字体名后假定 Word 会正确替换。

## 标题编号与目录

- 一级标题使用 `第1章、第2章、第3章……`。
- 二级标题使用 `1.1、1.2、1.3……`。
- 三级标题使用 `1.1.1、1.1.2、1.1.3……`。
- 正文中一级标题居中，二级和三级标题左对齐。
- 目录中一级标题左对齐；下一层标题依次向右缩进一层。
- 编号应使用可编辑的多级列表或稳定的段落编号配置，不要把全部编号硬编码成普通文本后再手工修改。

## 图、表与表格视觉规则

- 图、表按章节使用阿拉伯数字编号：`图1-1、图1-2、图2-1`；表格同理使用 `表1-1`。
- 图表对象居中。图注放在图下方，表题/表头说明放在表上方。
- 图注和表题使用宋体、五号（10.5 pt）、居中。
- 图表与上下文之间各空一行；不要让题注贴在上一段或下一段上。
- 表格表头横向、纵向均居中；分类、优先级、状态、编号等短标签横向、纵向均居中。
- 证据、方法、解释、限制和建议等叙述性单元格左对齐、纵向居中；超长内容确有必要时可改为顶端对齐。
- 使用有意图的列宽：编号/类型/状态/优先级等短列窄一些，证据和解释列宽一些；不要把所有列等宽处理。
- 使用适度单元格内边距、浅灰边框、统一的表头底色和克制的隔行底色。不得为了“看起来居中”而合并无语义关联的单元格。

## 公式

- 公式按章节使用阿拉伯数字编号，如 `(1-1)`、`(1-2)`。
- 编号放在本页公式行的右侧；长公式在符号允许处换行，编号放在最后一行。
- 正文引用统一写为 `公式(1-1)`。
- 公式说明至少交代关键符号、单位、假设和该公式在证据链中的作用。没有给出推导时，明确标注“原文未提供推导”，不要补写推导。

## 参考文献

参考文献按 **GB/T 7714—2015** 编排。常用文献类型/标识包括：普通图书 `M`、会议录 `C`、汇编 `G`、报纸 `N`、期刊 `J`、学位论文 `D`、报告 `R`、标准 `S`、专利 `P`、数据库 `DB`、计算机程序 `CP`、电子公告 `EB`、其他 `A`、舆图 `CM`、数据集 `DS`、其他 `Z`。

不能从来源确认作者、题名、年份、卷期、页码、DOI 或访问日期时，保留缺失标记并在质量说明中列为待核实项；不得为了使格式完整而臆造书目信息。

## 附录与编号

附录用于放置不宜进入正文但有参考价值的详细理论依据、研究方法和技术要点、补充信息、过长材料、原始数据、数学推导、计算程序、框图/结构图、统计表或计算输出等。每个附录按大写英文字母顺序编号：`附录A、附录B、附录C……`。

附录中的图、表、公式和参考文献与正文分开编号，并在阿拉伯数字前加附录序号：`图A-1`、`表B-2`、`式(B-3)`、`[A-4]`。

## 论文电子资料归档顺序

当用户要求交付完整毕业设计/论文资料包时，按下列顺序编辑后统一归档：

1. 毕业设计（论文）封面
2. 毕业设计（论文）任务书
3. 毕业设计（论文）评语表
4. 原创性声明、关于使用授权的声明
5. 中、外文摘要
6. 目录
7. 毕业设计（论文）正文
8. 结论
9. 参考文献
10. 附录
11. 致谢

外文翻译资料按以下顺序统一归档：外文翻译封面 → 外文原文 → 中文翻译。附件还要求外文翻译约 5000 字、内容与毕业设计（论文）题目相关；若用户没有要求生成翻译资料，不要在普通论文阅读报告中擅自添加翻译部分。

论文阅读报告虽然采用本格式的页面、字体、表格和题注规则，但不应凭空生成封面、任务书、评语表或声明。只有在用户提供对应模板或明确要求完整论文资料包时，才加入这些行政页面。

## 交付前检查

- DOCX 为真实可编辑文件，而非改后缀的 Markdown/PDF。
- A4、纵向、页边距、页眉/页脚距离和装订线准确。
- 页眉文字、页码字段、字体、字号、行距和段前段后符合本表。
- 章/节编号、图表编号、公式编号和附录编号连续且可定位。
- 图注在图下、表题在表上；表头和短分类单元格横纵居中；长叙述单元格可读。
- 参考文献按 GB/T 7714—2015 处理；不确定字段没有被臆造。
- 至少检查首页、最密集表格页、公式/图表页和末页的渲染结果；确认没有溢出、断裂、空白占位符或不可读表格。
